# Voicecart Project Rules

## Deployment Workflow
1. **Always push to GitHub first** - Commit and push all changes to the GitHub repository before any other deployment
2. **Ask before Netlify** - After pushing to GitHub, ask the user if they want to deploy to Netlify. Never auto-deploy to Netlify to conserve credits.

## Project Info
- Simple static HTML page (index.html)
- Hosted on Netlify
- No build process required
